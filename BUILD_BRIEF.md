# Build brief

- Intent: A reusable Nook-inspired new tab template in a separate sibling folder and Git repo.
- Audience: People who can clone a repo and build a browser extension; their end users can use Settings.
- Workflow: Clone, install, edit the config, preview, build, load the extension, customize, and return to saved settings.
- Scope: Existing Nook visual style; one typed config; settings; daily quote and photo rotation; direct three-dot drag handles, hover resize controls, and live snapped previews; local photo selection and storage; editable personal quotes and reminders; a background prompt; screenshot-based setup documentation; larger default notes; local persistence; extension build; setup and customization docs.
- Exclusions: Visual page builder, accounts, cloud sync, paid services, store publication, and public remote creation.
- Data: Starter data from config; personal data in local device storage; remote photos, fonts, and link icons.
- Acceptance: Separate repo; no copied Git history or personal environment files; type check and production build pass; config drives defaults and page content; rotation and layout tests pass; drag, reorder, resize, image cycling, and persistence checked in preview.
- Authority: User chose code template plus built-in settings. Routine reversible choices are agent decisions.
